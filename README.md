# VALIDAAD MUSIC

An Android-first music platform focused on offline music, compliant online discovery, and a signature listening experience.

## Project status

Foundation setup is in progress. Features will be marked complete only after they are implemented and tested on a real Android device.

## Initial technical direction

- Kotlin
- Jetpack Compose
- AndroidX Media3 for local playback
- Minimum Android API: 26 (Android 8.0)

## Development principles

- Respect music licensing and platform playback restrictions.
- Never claim a feature works until it has been tested.
- Keep API secrets out of the Android app.
